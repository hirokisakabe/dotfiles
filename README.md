# dotfiles

## 主なツール

| 役割       | ツール                     |
| ---------- | -------------------------- |
| ターミナル | WezTerm＋zsh               |
| エディタ   | VS Code                    |
| AIとの実装 | Claude Code／Codex         |
| 環境管理   | Homebrew＋mise             |
| macOS操作  | Raycast、Rectangle、AltTab |

## セットアップ

macOSとXcode Command Line Toolsを前提に、次を実行する。

```sh
make install
```

導入・更新・状態確認などのタスクは `make help` を参照。
